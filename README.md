# 🏥 Healthcare Revenue Cycle Reconciliation System

## 📌 Project Overview
This project simulates a real-world Healthcare Revenue Cycle Management (RCM) system using SQL.  
It models the complete financial lifecycle of a healthcare encounter — from patient visit to claim submission, payment collection, and denial analysis.

---

## 🏗 Database Schema

The system includes the following tables:

- **patients**
- **providers**
- **encounters**
- **claims**
- **payments**
- **denials**

The schema models real healthcare financial workflows including foreign key relationships.

---

## 💰 Revenue Cycle Flow

1. Patient visit (Encounter)
2. Claim submission
3. Insurance approval/denial
4. Payment posting
5. Revenue reconciliation
6. Financial performance analytics

---

## 📊 Key Analytics Implemented

- Total Billed Revenue
- Total Collected Revenue
- Revenue Leakage
- Denial Rate %
- Net Collection Rate %
- Average Days in Accounts Receivable
